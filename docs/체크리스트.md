# 📋 Insta Taste Recommender 최종 실행 & 검증 체크리스트 (체크리스트.md)

> 사용자가 인스타그램 데이터(ZIP)를 입력하고 실행했을 때, 프론트엔드(React)·백엔드(Vercel)·외부 API(DDGS)가 100% 정상 작동하는지 단계별로 점검하는 최종 검증 가이드입니다.

---

## 📲 0. 인스타그램 데이터 다운로드 시 체크 필수 항목 (Meta 옵션 선택)

인스타그램 앱/웹 ➡️ `설정` ➡️ `내 정보 다운로드` ➡️ `정보 유형 선택` 화면에서 **아래 3가지 항목은 반드시 체크**해야 합니다:

- [x] ✅ **`좋아요`** (취향 키워드 추출 지표 1)
- [x] ✅ **`저장됨`** (취향 키워드 추출 지표 2 - 무의식의 강력한 반영)
- [x] ✅ **`스토리 반응`** (취향 키워드 추출 지표 3 - 친밀도/관심사 반영)

## 🖥️ 1. 웹사이트 3단계 UX 정상 작동 체크리스트 (Client UI)

- [ ] **[Page 1: 업로드 랜딩 (`/`)]**
  - [ ] `.zip` 파일을 드롭존에 클릭하여 선택 시 유효성 검사(ZIP 파일 여부)가 작동하는가?
  - [ ] 파일 선택 후 '내 취향 분석 시작' 버튼이 활성화되고, 클릭 시 로딩 페이지로 전환되는가?

- [ ] **[Page 2: 파일 청크 전송 및 로딩 (`/loading`)]**
  - [ ] 하단 프로그레스 바가 **0%에서 100%까지 자연스럽게 상승**하며, Vercel로 2MB 청크 분할 전송이 이뤄지는가?
  - [ ] 전송 완료 후 백엔드 메모리 파싱(In-Memory Streaming) 및 취향 키워드 추출이 진행되며, 추천 결과(DDGS) 폴링(Polling)이 정상적으로 수행되는가?

- [ ] **[Page 3: 프로파일링 결과 뷰 (`/result`)]**
  - [ ] 분석 완료 시 화면에 **Confetti 축하 폭죽 애니메이션**이 팡 터지는가?
  - [ ] 👑 최상단에 **"당신의 인스타 자아는 [ #키워드 ] 마니아"** 형태의 성향 테스트(MBTI) 방식의 타이틀이 정상적으로 렌더링되는가?
  - [ ] 🌟 **일반 맞춤 추천 (SFW)** 리스트가 정상적으로 크롤링되어 나오는가?
  - [ ] 🔥 **당신의 숨겨진 취향 추천 (Secret Pick)** 리스트가 나오거나, 만약 민감한 키워드가 없다면 **"숨겨진 특별한 취향이 발견되지 않았습니다. 평범하고 건전한 라이프를 즐기고 계시네요! 😇"**라는 메시지가 정상 출력되는가?
  - [ ] 🔗 **"결과 공유하기"** 버튼 클릭 시 클립보드 복사가 정상적으로 완료되는가?

## 🌐 2. Vercel 및 백엔드 스크래핑 검증 체크리스트 (Backend Console)

- [ ] **Vercel `Deployments` 탭 검증**:
  - [ ] 최상단 빌드 상태가 **🟢 `Ready`** (초록색)로 표시되는가?
  - [ ] 인메모리 스트리밍(In-Memory Streaming)을 통해 800MB 대용량 ZIP 업로드 시에도 `/tmp` 용량 초과 에러(HTTP 500)가 발생하지 않는가?
  - [ ] DDGS(`duckduckgo-search`) 라이브러리를 통해 `site:instagram.com` 검색 시, 민감한 키워드 필터링 우회 치환 로직(Safe Dictionary)이 정상적으로 동작하여 빈 리스트(`[]`) 대신 결과값을 제대로 리턴하는가?
