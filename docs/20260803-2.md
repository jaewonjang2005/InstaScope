# 인스타 알고리즘 분석 프로젝트 - 구조 및 로직 개선 사항 정리 (2026.08.03)

## 1. 프론트엔드 - 서브 취향(Secret) / 매운맛(Spicy) 분리 로직 수정
- **문제점**: 매운맛 모드를 토글(ON)해도 프론트엔드의 화면 색깔만 바뀔 뿐, 추천 키워드와 추천 콘텐츠가 변경되지 않는 버그가 존재했습니다.
- **해결 방안 (`SecretPickPage.jsx`)**:
  - `isSpicyMode` 토글 상태에 따라 보여주는 데이터를 명확히 분리했습니다.
  - **OFF (서브 취향)**: `hidden_category`, `hidden_keywords`, `hidden_recommendations` 데이터를 화면에 렌더링.
  - **ON (매운맛)**: `spicy_category`, `raw_hidden_tags` (매운맛 전용), `spicy_recommendations` 데이터를 화면에 렌더링.
  - 추가로, 최상단 제목 텍스트에 하드코딩된 문자열 대신 각 모드에 맞는 **메인 거시적 카테고리(Macro Category)** 변수가 출력되도록 수정했습니다.

## 2. 백엔드 - 동시 출현(Co-occurrence) 기반 키워드 추출 알고리즘 도입
- **문제점**: 하드코딩된 사전을 배제하고, 무작정 사용자가 많이 소비한 '빈도수 Top 5' 태그를 추출하다 보니, **'동기부여'** 카테고리 안에 전혀 상관없는 **'jpop'**, **'fyp'** 같은 태그가 난잡하게 섞여서 나오는 '주제 불일치' 문제가 발생했습니다.
- **해결 방안 (`keyword_extractor.py`)**:
  - **단어장/사전(하드코딩) 사용 0%**: 외부 단어 사전에 의존하지 않고 수학적 모델링으로만 해결했습니다.
  - **Co-occurrence Tracking**: 사용자의 데이터를 분석할 때, **'하나의 릴스(게시물) 안에서 같이 등장한 해시태그들의 짝(Pair)'** 을 카운트하여 서로 간의 끈끈한 '연관성 점수(Network Score)'를 기록하도록 엔진을 업그레이드했습니다.
  - **추출 방식 개선**: 
    1. 빈도수가 가장 높은 태그 딱 하나를 **주된 주제(Main Category)**로 선정합니다.
    2. 나머지 3~4개의 핵심 키워드들은 전체 랭킹에서 뽑는 것이 아니라, 오직 **'주된 주제와 함께 묶여 다녔던(연관성 점수가 높은) 태그들'** 중에서만 가져옵니다.
  - **결과**: `SFW(일반 취향)`, `Secret(서브 취향)`, `Spicy(매운맛)` 세 영역 모두에 이 알고리즘을 적용하였으며, 그 결과 메인 주제에 완벽하게 부합하는(예: 동기부여 -> 자기계발, 성공명언 등) 파생 키워드들만 정돈되어 출력됩니다.

## 3. 긴급 오류 수정 사항 (Hotfix)
- **문제점**: 코드 리팩토링 중 실수로 삭제되었던 중복 태그 필터링 함수로 인해 발생했던 백엔드 빌드 충돌 오류(`NameError`).
- **해결 방안 (`keyword_extractor.py`)**: `filter_similar_tags` 및 `is_similar` 보조 함수를 즉각 복구 후 Vercel 환경에 재배포하여 시스템 정상화 완료.
